# Rust + io_uring (`rust-uring-theCatWisel`)

- **Language:** Rust (`1.100.0`, zero external Cargo crates)
- **Framework:** Custom HTTP/1.1 reactor on raw Linux `io_uring` (`SINGLE_ISSUER | DEFER_TASKRUN | COOP_TASKRUN | NO_SQARRAY`, registered sparse direct descriptors, dual provided receive buffer rings with `IORING_RECVSEND_BUNDLE`, bounded `io-wq` pools, and `epoll_pwait2` fallback)
- **Database Driver:** Custom asynchronous PostgreSQL v3 extended-query wire client (`SCRAM-SHA-256`, pipelined `Bind`/`Execute`/`Sync`, mixed text/binary `timestamptz` row streaming)

## Architecture

1. **Isolated Prefork Reactors & `2 MiB` `.text` Collapse:** Before forking, the parent maps the `2 MiB`-aligned executable segment into an anonymous `MADV_COLLAPSE` hugepage, restores `PROT_READ | PROT_EXEC` permissions via `mremap`, seals the mapping with `mseal()`, and disables ambient heap transparent hugepages (`PR_SET_THP_DISABLE` / `MADV_NOHUGEPAGE`). One single-threaded worker process is forked per available CPU (`sched_getaffinity`); each worker calls `unshare(CLONE_FILES)` and binds `SO_REUSEPORT` listeners across `PORT` and `EXTRA_PORT` with `TCP_DEFER_ACCEPT`, `TCP_THIN_LINEAR_TIMEOUTS`, listener-inherited `TCP_QUICKACK = 0`, and socket-scoped `TCP_CONGESTION = bbr` (falling back automatically if unavailable).
2. **Direct Descriptors & Bundled Provided Receive Rings:** Each worker registers its ring descriptor (`IORING_REGISTER_RING_FDS`), bounds helper kernel threads (`IORING_REGISTER_IOWQ_MAX_WORKERS`), allocates a sparse direct-descriptor table (`IORING_REGISTER_FILES2`), and attaches two provided receive buffer rings (`IORING_REGISTER_PBUF_RING`): a `2 KiB` buffer group for client HTTP sockets and a `32 KiB` buffer group (`IORING_RECV_MULTISHOT | IORING_RECVSEND_BUNDLE` when supported by the kernel) for PostgreSQL v3 sockets. Client connections are accepted directly into `io_uring` fixed slots via multishot `IORING_OP_ACCEPT` (`IORING_FILE_INDEX_ALLOC`) and read via multishot `IORING_OP_RECV` without per-connection idle heap buffers.
3. **TX-Aware Single-Syscall CQE Coalescing & Idle Ring Heartbeat:** A `1 Hz` `IORING_OP_TIMEOUT` SQE maintains background connection sweeps at zero idle CPU while avoiding per-syscall kernel `hrtimer` setup when uncongested. Under high concurrency, completion batches account for outbound `SEND` completions in `min_complete` so pending transmits and new inbound socket bursts coalesce inside a single `io_uring_enter` call (`IORING_FEAT_MIN_TIMEOUT` or `IORING_ENTER_EXT_ARG`), while non-essential close/cancel completions are suppressed via `IOSQE_CQE_SKIP_SUCCESS`.
4. **Zero-Copy PostgreSQL v3 Pipelining & Durable Write Batches:** Worker read and write lane counts scale per core count within the 512-connection cap and are driven end-to-end through `io_uring` multishot `IORING_OP_RECV` and `IORING_OP_SEND`. All five `SPEC.md` statements are prepared once per connection (`plan_cache_mode = force_generic_plan`, `jit = off`) and dispatched across idle lanes in pipelined batches terminated by `Sync`. Feed and post queries request mixed column formats (`id`, `body`, `username`, and `like_count` as text digits/UTF-8 alongside binary `timestamptz`), streaming `DataRow` spans directly out of the `32 KiB` provided buffer rings into pointer-bumped JSON buffers formatted with wide 64-bit stores. Write responses (`201`, `200`, `404`) are transmitted only after `ReadyForQuery` confirms synchronous WAL commit durability; if a write batch encounters a foreign-key error (`23503`), unaffected sibling writes are replayed individually before replying.
5. **Hardware Crypto, Single-Pass Vector Scans, and Stateless Compression:** Authenticated requests decode tokens via `SSSE3` vectorized `base64url` shuffles and validate the `HS256` header, signature, and `exp` claim before path validation using runtime-dispatched `SHA-NI` or `AVX2+BMI2` (`rorx`/`andn`) compression initialized from precomputed HMAC `ipad`/`opad` midstates. Request bodies and claim strings without escape sequences are borrowed directly out of receive buffers, while JSON string escaping writes optimistically from SIMD registers (`AVX-512BW` on `VAES`-capable cores and `256-bit` `AVX2` on pre-`VAES` `AVX-512` cores to avoid 512-bit turbo frequency downclocking). Responses at or above the compression threshold are compressed statelessly per request via statically linked Intel `ISA-L` (`v2.31.1`) using a static DEFLATE Huffman symbol table calibrated from live outbound JSON byte frequencies and periodically refreshed when `Accept-Encoding: gzip` is present. `build.sh` runs two-stage `llvm-profdata` profile-guided optimization with `-Wl,-z,separate-code,-z,max-page-size=2097152`, LLVM `ext-tsp` machine block placement, hot-cold machine function splitting, and `rust-lld` `cdsort` call-graph section layout.
